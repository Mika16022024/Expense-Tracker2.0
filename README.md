# 💰 Expense Tracker

A simple web-based expense tracker built with HTML, CSS and JavaScript.

## Features

- Add expenses
- Categorise expenses
- Calculate total spending
- View spending by category
- Delete expenses
- Save expenses using localStorage
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

This project helped me practise JavaScript fundamentals, including:

- Variables
- Functions
- Events
- DOM manipulation
- Arrays
- Objects
- localStorage
- Input validation
